# v1.1.3: Season odds without an API key

Season odds now work with just your Epic name. Before, every player had to sign up at Fortnite-API.com and paste in their own key. That step is gone.

## What's new
- **No key needed.** On the **Season odds** tab, type your Epic name and click **Refresh stats**. Your season matches, wins and loot odds load straight away.
- **Automatic End game only needs your Epic name** too.
- **Your own key is still an option.** If you already use one, nothing changes. Leave **Own API key** empty to use the shared service, or paste your key in to use it directly.
- **Clearer messages** if the shared service is ever busy or down, with a reminder that you can add your own free key to keep going. Counting, games, friends and the overlay never depend on it.

## How it works
Lookups without a key go through a small shared service that adds the key on its side, so the key never ships inside the app. It only looks up season stats and remembers each name for a minute so it stays fast. Your Epic name is the only thing it sees.

## Updating
Download `ChestCounter.zip` below, quit Chest Counter from the tray, replace `ChestCounter.exe` and start it again. Your stats, games and settings carry over.
