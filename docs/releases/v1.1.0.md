# v1.1.0: First public release

Chest Counter is a free overlay for Fortnite that counts the chests you open. Press a button when you open a chest and a small counter in the top-left of your screen goes up. Press another when the match ends and it saves the game.

## Features
- **Count with any button:** a keyboard key, Mouse 4/5, or a controller button. Your button still works in-game as normal, and holding it down counts once.
- **Overlay on top of Fortnite** (Window Mode: Windowed Fullscreen). It's click-through and only shows while Fortnite is open.
- **Every game saved:** game number, average chests per game, best game, total and a list of past games. **Undo last save** puts the chests back if you pressed End game by mistake.
- **Season loot odds:** pulls your season matches, estimates how many chests you've opened this season, and shows your chance of each drop, from the Weekly Loading Screen (1 in 272) up to the Weekly Gold Outfit (1 in 1,562,500). Flip **Got it** when you get one.
- **Weekly items:** press **New week** when the week resets. Weekly items restart while Pirate Shop Access keeps counting all season.
- **Friends:** share a room code to see each other's counters and odds live on your overlay.
- **Automatic End game (optional, off by default):** saves each game for you when Fortnite records the match.
- **Update check:** tells you when a new version is out.

## Getting started
1. Download `ChestCounter.zip` below, unzip it and run `ChestCounter.exe`. No install needed.
2. If Windows says "Windows protected your PC", click **More info → Run anyway**. It shows that because the app isn't code-signed.
3. Pick your chest button and your match-end button, and you're counting.

It never reads or changes Fortnite's files or memory. It only listens for your button, like Discord push-to-talk. Not affiliated with Epic Games.
