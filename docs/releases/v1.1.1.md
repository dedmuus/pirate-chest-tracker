# v1.1.1: Automatic End game toggle fixed

## Fixed
- **The Automatic End game switch now stays on.** In v1.1.0, clicking it flipped it on and then straight back off, so automatic End game never actually ran. It now turns on, and the line under it shows when it last checked your stats.

## Reminder: how automatic End game works
- Turn it on in the **Season odds** tab. It's off by default.
- While Fortnite is open, it checks your season stats once a minute. When a new match shows up, it saves your game for you.
- Chests you open in the next match stay in the next match, even though the stats arrive a few minutes late.
- Your End game button still works, and pressing it won't save the same match twice.

## Updating
Download `ChestCounter.zip` below, quit Chest Counter from the tray, replace `ChestCounter.exe` and start it again. Your stats, games and settings carry over.
